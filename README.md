Device configuration for Samsung Galaxy Tab S7 FE 5G (SM-T736B, gts7xllite)
===========================================================================
The Samsung Galaxy Tab S7 FE 5G is an upper mid-range tablet from Samsung.

It was announced in June 2021 and released in August 2021.

## Tablet specifications

Basic    | Spec Sheet
--------:|:----------------------
SoC      | Qualcomm Snapdragon 750G (SM7225)
Modem    | Snapdragon X52 5G (sub-6)
CPU      | Octa-core Kryo 570 (2x 2.2GHz + 6x 1.8GHz)
GPU      | Adreno 619
Memory   | 4,6,8GB RAM
Storage  | 64,128,256GB UFS
Expansion | Expandable up to 1TB via microSD
Shipped Android version | Android 11, OneUI 3
Battery  | Li-ion 10090mAh, non-removable, 45W Wired
Display  | TFT LCD, 60Hz, 12.4 inches, 2560 x 1600 pixels, 16:10 ratio
Camera Back  | 8 MP
Camera Front | 5 MP
Video        | 1080p@30fps
Sensors      | Accelerometer, Gyroscope, Compass, Hall sensor
